## 板卡定位

一块「主控 + 电机驱动」合板：STM32F103C8T6、两颗双 H 桥、电源转换、PS2 接收器座、电机端子全部收在一张 2 层板上，对外只留电池输入与手柄接收器插口。

这样做的理由是减少杜邦线：第一版用模块搭时，电机线、方向线、使能线二十多根，任何一根接触不良都表现为「电机不转」，排查成本极高。合板后这些连接变成板内走线，只剩电源、电机、手柄三类外部接线。

| 项目 | 内容 |
| --- | --- |
| 设计工具 | 嘉立创 EDA（原理图 + PCB） |
| 打样 | 嘉立创（2 层 / 1.6 mm / 1 oz 铜 / 绿油白字） |
| 器件来源 | 立创商城（主控、DRV8833、电源芯片、连接器） |
| 主控 | STM32F103C8T6（Cortex-M3，64 KB Flash / 20 KB SRAM） |
| 电机驱动 | DRV8833 ×2（前级 FL+FR、后级 BL+BR） |
| 电源 | 电池组 → 板载 **LM2575S-5.0**（Buck）5 V → **AMS1117-ADJ**（LDO）3.3 V |

## 设计流程（嘉立创全流程）

| 步骤 | 做法 | 检查点 |
| --- | --- | --- |
| 1. 需求与引脚规划 | 先列「要驱动什么、要几路 PWM、要几个脚」，再对照 F103 复用功能表选脚 | 每个引脚在软件里怎么用必须写清 |
| 2. 选器件 | 立创商城逐个确认型号、封装、库存、是否可贴片 | 封装与符号成对确认，避免「有图无件」 |
| 3. 画原理图 | 按功能分块：主控最小系统 / 电机驱动 / 电源 / 接口 | 网络名带电压值；每个电源脚配去耦电容 |
| 4. 导入 PCB | 布局按「电流路径最短」排：电池 → 降压 → 驱动 → 电机端子 | 大电流器件靠近连接器，主控远离功率区 |
| 5. 走线 | 功率线先走（宽、短），再信号线，最后铺铜 | 功率地与信号地分区、单点汇合 |
| 6. DRC + DFM | 先清 DRC，再跑嘉立创 DFM | DRC 全绿不等于好用，人工复核去耦与丝印 |
| 7. 出 Gerber / BOM | 导出后用 3D 或 Gerber 预览自查 | 丝印不压焊盘；位号不重复 |
| 8. 下单打样 | 2 层板，常规工艺 | 记录板厂回传工艺参数，便于复现 |
| 9. 收货核对 | 万用表逐段测通断，再上电 | **先测 VM 与 GND 是否短路**，再插电池 |

## 电源树

```
电池组（DC 座输入，板上网络 VCC）
        │
      SW1 拨动开关
        │
      +12V ─┬── VM ─────────────────────► DRV8833 ×2 (VM 允许 2.7~10.8 V) ──► 四路电机
             │
             └── U8 LM2575S-5.0（Buck）──► +5V ─┬──► PS2 接收器
                                                  ├──► 板边 +5V 排针
                                                  └── U3 AMS1117-ADJ（LDO）──► +3V3
                                                                                  ├──► STM32F103 主控
                                                                                  └──► OLED / 舵机逻辑侧
```

| 档位 | 来源 | 负载 | 设计要点 |
| --- | --- | --- | --- |
| VM（+12V 经开关） | 电池组经 DC 座与 SW1 直供 | DRV8833 ×2 | 大电流路径，宽、短，靠端子就近去耦 |
| +5V | 板载 Buck（U8 LM2575S-5.0） | PS2 接收器、降压级输入、5 V 排针 | 承担大压差，开关方案保证效率 |
| +3V3 | 板载 LDO（U3 AMS1117-ADJ） | STM32F103（几十 mA）、OLED | 压差 1.7 V，损耗 < 0.1 W；兼滤开关纹波 |

**为什么不是一颗 LDO 直接从 12 V 降到 3.3 V**：压差 8.7 V，几十毫安负载就要白白发热近 0.5 W，SOT-223 靠铺铜撑不住。级联让开关级吃掉压差、LDO 负责干净输出，是这块板的核心电源决策。

> ✅ 降压电路为**本队自绘**、直接做进主板，不是外挂成品模块。文档 [01](./01-整体方案与硬件设计.md) 的「DC-DC 降压模块」表述需据此改写。

### 两级降压电源电路（自绘，非成品模块）

电源没有买现成模块，而是从原理图开始自己画、自己选型、自己布进板里。市售模块的排针、电位器、尺寸都不受控，插拔与振动下会成为新的接触点故障；而两级降压只有一颗 Buck、一颗 LDO、一个电感、四颗电容和几颗阻容，完全画得进板。

| 级 | 器件 | 拓扑 | 输入 → 输出 | 供电对象 |
| --- | --- | --- | --- | --- |
| 一 | U8 **LM2575S-5.0(UMW)** | 开关降压（Buck） | +12 V → +5 V | PS2 接收器、5 V 排针、第二级输入 |
| 二 | U3 **AMS1117-ADJ** | 线性稳压（LDO） | +5 V → +3.3 V | STM32F103 主控、OLED |

**第一级 LM2575S-5.0**：固定 5 V 输出，52 kHz，1 A，输入上限 40 V；储能电感 L1 = 33 µH 串在 `OUTPUT` 与 +5 V 之间，输入 C1 = 680 µF、输出 C2 = 220 µF；`FB` 直接接输出（固定版内部已有分压），`ON#/OFF` 接地常开，GND 与散热焊盘（第 8 脚）一起下地。

**第二级 AMS1117-ADJ**：1.25 V 基准的可调 LDO，输出由外部分压设定

$$V_{out} = 1.25\ \text{V} \times \left(1 + \frac{R_{top}}{R_{bot}}\right)$$

输入 C4 = 10 µF、输出 C3 = 10 µF，满足 AMS1117 对输出电容最小容值的要求，否则可能自激；压差 1.7 V、负载几十 mA，损耗约 0.05~0.1 W。

**串联的理由**：Buck 效率高但纹波大、开关噪声宽；LDO 噪声低但压差全变热。串联后前者吃压差、后者滤噪声，代价只有那 1.7 V × 几十 mA。

**自绘电路在布局上的要求**：

| 要点 | 做法 | 原因 |
| --- | --- | --- |
| 开关环路最小 | C1、U8、L1、C2 紧靠成一条线 | 环路面积决定辐射与输出尖峰 |
| 地回路 | 输入电容与 U8 的 GND 用短线回功率地 | 大 di/dt 不能从主控地借路 |
| 反馈取样点 | 从输出电容 C2 端取，不从电感端取 | 取在电感上会把纹波引入反馈环 |
| 输出电容 | C2 贴近 LDO 输入 | 给 LDO 提供就近瞬态电流 |
| 远离信号区 | 电感与 DC 座靠板边，与晶振、PS2 座分开 | 避免噪声耦合到时钟与通信线 |

> ⚠️ **按 V1.0 原理图复核出的四项待确认**（打样/贴片前逐项确认）：
>
> | 项 | 图上现状 | 风险 |
> | --- | --- | --- |
> | 续流二极管 | `OUTPUT`–`GND` 之间未见肖特基二极管 | 非同步 Buck 必须有续流回路，缺了出不了 5 V |
> | 电感取值 | L1 = 33 µH | 手册 5 V/1 A 典型值约 100 µH；33 µH 是 150 kHz 器件（如 LM2596）的口径，52 kHz 下纹波电流明显偏大 |
> | 反馈分压 | R4 = 125 Ω（上）、R3 = 205 Ω（下）→ **≈ 2.0 V** | 与 +3.3 V 网络名不符；两者对调才是 3.30 V，需按 BOM / 丝印确认 |
> | 指示灯限流 | 3.3 V 侧 R1 = 10 Ω | LED 电流约 130 mA，远大于常规值（5 V 侧 R2 = 220 Ω 正常） |
>
> 这四项都属于「原理图阶段能拦住、打样后只能飞线」的问题。

### 供电合规性

- 手册 3.2 要求整机**只有一个供电模块**、额定电压不超过 **7.4 V**；
- 2 节 18650 串联标称 7.4 V、满电 8.4 V，这一点必须在提交说明里写清；
- 无线继电器串在电池与底盘电源之间，用于 10 m 内独立切断动力，属安全要求。

## DRV8833 电路设计

每颗 DRV8833 驱动同侧两个电机，两颗覆盖四轮。

| 引脚 | 接法 | 理由 |
| --- | --- | --- |
| VM | 电池组正极（+12V 网络） | 7.4 V 标称落在 2.7~10.8 V 范围内 |
| GND / PowerPAD | 功率地铺铜 + 过孔阵列 | 散热焊盘必须实焊导热，否则带载发热保护 |
| AIN1/AIN2、BIN1/BIN2 | FL_IN1（PWM）/ FL_IN2（方向），FR 同 | 符号-幅值控制 |
| AOUT1/AOUT2、BOUT1/BOUT2 | 经 H2 与 KF301 端子引出 | 接电机 |
| nSLEEP（丝印 STBY） | PB0，经电阻上拉 | 内部下拉，悬空即休眠，必须外部拉高 |
| VCP | 0.01 μF 到 VM | 电荷泵必需电容，缺了上管驱不起来 |
| AISEN / BISEN | 直接接地 | 不做电流检测，按手册要求接地 |
| nFAULT | 预留上拉 | 开漏输出，可做故障检测，目前软件未用 |
| VM 去耦 | 10 μF + 0.1 μF 就近放置 | 给 H 桥开关尖峰提供就近电流 |

**命名差异**：板上丝印 `STBY1/STBY2`（沿用 TB6612 说法），芯片实际是 `nSLEEP`。两者功能等价（高电平工作），软件不受影响，但对引脚时要知道这是两个器件的叫法。

## VCC / GND 与走线

| 措施 | 做法 | 目的 |
| --- | --- | --- |
| 电源分区 | 功率区（降压、DRV8833、电机端子）与信号区（主控、晶振、PS2 座）分开布局 | 避免功率热量与大电流回路干扰主控 |
| 地分区 | 功率地、信号地各自铺铜，电池输入端单点汇合 | 电机脉冲电流不在主控参考地上产生压降 |
| 去耦 | 每个电源脚就近 0.1 μF，VM 处 10 μF + 0.1 μF | 就近提供瞬态电流，压缩高频环路 |
| 铺铜 | 双面铺地 + 过孔缝合 | 降低地阻抗，给回流提供紧贴信号线的路径 |
| 网络命名 | VM / +5V / +3V3 分开命名，不用统一 VCC | 原理图阶段就防止高压接到低压脚 |

| 网络 | 线宽 / 处理 | 依据 |
| --- | --- | --- |
| 电池主干（VM） | 铺铜 + 1.5 mm 级宽线，多过孔并联 | 四电机同时启动的瞬态电流约 3 A 量级 |
| 单路电机输出 | 0.8 mm | 单路 DRV8833 连续 1.5 A |
| 5 V / 3.3 V | 0.5 mm | 负载几十 mA，余量充足 |
| PWM / 方向信号 | 0.25 mm | 纯逻辑信号，无载流要求 |
| 功率地 | 铺铜 | 回流路径，越宽越好 |
| 晶振 / 复位 | 短，下方不走其他信号 | 避免串扰导致跑飞 |

**关键原则**：大电流回路（电池 → 驱动 → 电机 → 地 → 电池）面积要小——环路面积大等于一根天线，既向外辐射也容易被干扰。上表线宽是按 IPC-2221 估算的设计值，未做实测校正；大电流路径一律优先铺铜。

## 打样、焊接与问题记录

| 阶段 | 做法 | 结果 |
| --- | --- | --- |
| Gerber 输出 / 下单 | 嘉立创 EDA 导出，2 层 / 1.6 mm / 1 oz | ✅ 已打样，板卡到手 |
| 焊接 | 阻容与主控按需 SMT 或手工焊；DRV8833 的 PowerPAD 需热风或回流 | ✅ 已焊 |
| 上电前检查 | 万用表测 VM–GND、+5V–GND、+3V3–GND 是否短路 | 必做项 |
| 首次上电 | 先只接电池不接电机，量三档电压 | 必做项 |

PowerPAD 是手工焊最容易出问题的地方：焊盘接触不实时空载完全正常，连续带载就发热进保护，表现为「跑一会儿停一下、凉了又能跑」。判据是满占空比连续运行测壳温，而不是只看转不转。

| 问题 | 现象 | 硬件侧原因 | 处理 |
| --- | --- | --- | --- |
| 丝印 `+12V` 与方案不符 | 板上标 +12V，实际电池标称 7.4 V（满电 8.4 V） | 命名沿用通用板习惯 | 接线前确认有无升压环节，文档显式记录口径差异 |
| PB3/PB4/PB5/PB6 为空脚 | 软件按 SPI1 重映射配置后毫无反应 | 画图时这四个脚没有引出功能 | 软件改用 PA4~PA7 模拟时序；根因是引脚规划未核对软件用法 |
| PS2 四线在板上交叉 | 硬件 SPI 无法使用 | CLK/CMD 与 SCK/MOSI 互换，DI 落在 NSS | 改软件模拟，不改已打样的板 |
| 右侧电机反向 | 直行时右侧两轮反转 | H2/H4 的 6、7 脚与左侧相反 | 软件 `set_reversed(true)`，或改排线 |
| ST-LINK 读回 0.00 V / 1.36 V 且跳变 | `Unable to get core ID` | 目标板未正常供电或 SWD 未共地 | 确认供电后连接成功 |
| 电机不转但寄存器写入正常 | CCR 已写入 3600，引脚无波形 | 引脚未配复用推挽、TIM1 未置 MOE | 见文档 [02](./02-底盘运动.md) |

**最值得记住的一条**：本板绝大多数问题不是焊接，而是**原理图阶段的引脚规划与软件预期不一致**。板子打样后软件只能绕着硬件走，下次画板前应先写「引脚-功能-软件用法」对照表逐项核对。
