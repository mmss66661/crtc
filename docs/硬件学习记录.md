## 1. 嘉立创 EDA：原理图与 PCB 是同一份数据的两个视图

### 理解

- **原理图不是「画着好看」的图**：它的本质是一张**网络表（netlist）**——每个引脚的连接关系被记录成「网络名 → 引脚列表」，PCB 只是把这些网络换成铜皮。改原理图等于改网络表，PCB 必须重新导入，这是最容易出「改了图忘了同步」的地方。
- **符号（Symbol）≠ 封装（Footprint）**：符号只负责逻辑连接，封装负责物理焊盘。两者靠「器件」这一层绑定。选器件时应先在立创商城确认**有货且封装正确**，再画图 —— 顺序反了就会出现「图画完了，封装买不到」。
- **DRC（设计规则检查）不是万能的**：它只能查出「线太细、间距太近、未连接」，查不出「线走错了地方」「去耦电容放远了」。DRC 全绿只代表能制造，不代表能用。
- **嘉立创的流程闭环**：EDA 出 Gerber + BOM + 坐标文件 → 下单打样 → 可选 SMT 贴片 → 收货后自己核对丝印与网络。**出图前必须做 DFM 检查**，否则常见问题是焊盘太小、丝印压焊盘、过孔离焊盘太近。

### 容易踩的点

- 网络名打错一个字（`VCC3V3` 写成 `VCC3.3`）→ 变成两个无关网络，DRC 不报错，板子回来才发现这段没连上；
- 复制粘贴器件时忘改位号，出现两个 `R1`。

## 2. 引脚：软件与硬件的交界线

### 理解

- **引脚是硬件对软件做出的承诺**：原理图上「PA8 接 FL_IN1」这句话，一旦打样就固定了。软件里写 `TIM1_CH1 → PA8` 才有意义，写错了软件再对也没用。
- **引脚复用能力必须在画原理图时查表**：STM32F103 的每个脚有固定的复用功能表（`PA8 = TIM1_CH1`、`PA9 = TIM1_CH2`…）。画图时选脚，等于提前决定了软件能用哪些外设。
- **空脚是最贵的浪费**：本板第一版的教训是 PB3/PB4/PB5/PB6 没有引出功能，而这些脚在常见开发板上正好是 SPI1 重映射的位置。软件按常见接法一写，整组外设就悬空了。
- **焊盘、过孔、排针都是引脚的物理形态**：同一个网络在 PCB 上可能同时出现在排针（H1）、测试点、和器件焊盘上，它们在电气上是同一个点。

### 记住的一条

> 画完原理图，逐个功能问一句「这颗脚在软件里会怎么用」，比打样后再飞线便宜一个数量级。

## 3. VCC 与 GND：电源网络不是一个名字，而是一条路径

### 理解

- **VCC 不是「电源」，GND 不是「零电位垃圾桶」**：电流从 VCC 流出、必须从 GND 流回，两者构成**回路**。回路的面积决定了这块板对外辐射多少、对外界干扰多敏感。
- **网络命名要带电压值**：本板有 `VM`（电池组，7.4 V 级）、`+5V`（PS2 接收器）、`+3V3`（主控）三档。名字写清电压，可以避免把 7.4 V 接到 3.3 V 的脚上 —— 一次接错就烧一片。
- **每个电源脚都要有去耦电容**，且**尽量靠近引脚**：电容与引脚之间的走线本身是电感，走 10 mm 和走 2 mm 的去耦效果差一个数量级。常规配置是 0.1 μF 贴片给高频、10 μF 给瞬态。
- **地要分「脏」「净」**：电机是脉冲大电流负载，主控是毫安级小信号负载。两者共用一段地线时，电机电流在地线电阻上产生的压降会叠加到主控的参考地上，表现为复位、ADC 抖动、通信误码。做法是**功率地与信号地分区铺铜，单点汇合**。
- **GND 是回流路径**：高频信号的回流走的是紧贴信号线的地平面，所以信号线下方尽量不要开槽 —— 回流被迫绕路，环路面积变大，干扰随之增加。

### 没吃透的地方

- 「分区 + 单点汇合」与「整块完整地平面」哪种更好，取决于电流大小与频率，目前只能按经验处理，没有做过对比测试；
- 地弹（ground bounce）在本板这种电机 PWM（20 kHz）场景下具体有多大，尚未实测。

## 4. LDO 与 DCDC：两条降压路线

### 理解

| 维度 | LDO（线性稳压） | DCDC（开关降压） |
| --- | --- | --- |
| 原理 | 调整管像一个可变电阻，多余的压差变成热 | 开关管 + 电感 + 二极管/同步管，靠占空比搬运能量 |
| 效率 | ≈ Vout / Vin，压差大时效率很低 | 通常 80%~95%，与压差关系小 |
| 发热 | $P = (V_{in}-V_{out}) \times I$，全部是热 | 损耗主要在开关与电感，发热小 |
| 噪声 | 输出很干净，无开关纹波 | 有开关纹波与高频噪声，布局敏感 |
| 外围 | 通常只需输入/输出电容 | 需要电感、输入输出电容、反馈电阻 |

**选择规则**：

- 压差小、电流小、对噪声敏感 → **LDO**。主控 3.3 V 从 5 V 降，压差 1.7 V、电流几十 mA，损耗不到 0.1 W，LDO 是最省事的选择。
- 压差大、电流大 → **DCDC**。从 7.4 V 电池组直接降到 3.3 V，压差 4 V 以上，若用 LDO，损耗是负载功率的好几倍，SOT-223 封装直接过热。
- **级联**：电池 → DCDC 降到 5 V → LDO 降到 3.3 V。这是本板采用的思路：DCDC 承担大压差，LDO 负责把开关纹波再滤一遍，兼顾效率与干净电源。

### 关键参数

- **LDO 的压差（dropout）**：输入必须比输出高出这个值才能稳压。常见 3.3 V LDO 的压差在 1.1 V 量级，所以 5 V 输入是够的，但**掉到 4 V 就会失稳**——电池快没电时要注意这一条。
- **LDO 的热**：SOT-223 的热阻约 60~80 °C/W，功耗 0.3 W 时温升二十多度，勉强可接受；功耗到 1 W 就必须换 DCDC 或加铜皮散热。
- **DCDC 的布局比选型更重要**：输入电容要紧贴 VIN 与 GND（高频电流环路最小），SW 节点铜皮要小（它是最大的噪声源），电感靠近 SW，反馈（FB）走线远离 SW 并从输出电容之后取。布局错了，再好的芯片也出不了标称纹波。
- **DCDC 的开关频率**决定纹波频率与电感体积：频率高则电感小、纹波频率高（好滤），但开关损耗与 EMI 上升。

### 没吃透的地方

- 纹波到底多大算「够用」，目前只知道主控要几十 mV 量级，没有实测数据；
- 电感选型（饱和电流、直流电阻、屏蔽与否）只看过手册，没有对比过实际效果。

## 5. 走线：把网络变成铜

### 理解

- **走线同时是电阻和电感**：直流下按电阻算（压降），高频下按电感算（阻抗、边沿变缓、辐射）。所以同一条线的「好」与「不好」要分频段看。
- **线宽由电流决定**。按 IPC-2221 的估算（1 oz 铜、外层、允许 10 °C 温升），大致是：

| 线宽 | 载流能力（估算） | 典型用途 |
| --- | --- | --- |
| 0.25 mm | ~0.8 A | 信号线、上拉/下拉 |
| 0.5 mm | ~1.4 A | 单路电机输出 |
| 0.8 mm | ~2.0 A | 电机供电支路 |
| 1.5 mm | ~3.0 A | 电池组主干、公共地 |

> 这是估算值，不是实测值。真正的大电流路径应该**铺铜**而不是拉细线。

- **压降比载流更容易被忽略**：3 A 电流走 0.5 mm 宽、30 mm 长的一段线，压降可以有几十 mV 到上百 mV，直接吃掉电机的有效电压。
- **走线要短、要直、要少拐角**：大电流回路（电池 → 驱动 → 电机 → 地 → 电池）的面积越小越好；换层用多个过孔并联，单个过孔的载流能力有限。
- **信号线避免与电源/电机线长距离平行**：平行走线之间有容性耦合，PWM 边沿会串到信号上（典型表现是通信偶发误码）。
- **晶振、复位这类敏感网络**：走线尽量短、下方不走其他信号、必要时包地。

### 没吃透的地方

- 走线电感对 20 kHz PWM 边沿的实际影响没有量化过；
- 阻抗控制（差分、等长）在这块低速板上是否需要，目前判断是「不需要」，但没有验证依据。

## 6. DRV8833：一颗双 H 桥的用法与外围

### 理解

DRV8833 是**双路 H 桥**，每路可驱动一个直流电机（或一个步进绕组），核心特性与外围要点如下：

| 项目 | 参数 / 做法 |
| --- | --- |
| 电机电压 VM | 2.7~10.8 V（本板电池组 7.4 V 标称 / 8.4 V 满电，落在范围内） |
| 单路电流 | 1.5 A 连续（RMS）、2 A 峰值 |
| 控制方式 | 每路两个逻辑输入 AIN1/AIN2（或 BIN1/BIN2），真值表决定正转/反转/刹车/滑行 |
| 使能 | **nSLEEP**：低电平进入休眠，**内部下拉**，因此悬空即休眠，必须外部拉高 |
| 电流检测 | AISEN/BISEN 外接采样电阻；不用时**直接接地** |
| 电荷泵 | VCP 与 VM 之间接 **0.01 μF** 电容，用于驱动上管 |
| 故障输出 | nFAULT 开漏，需外部上拉，低电平表示过流/过温 |
| 去耦 | VM 到 GND 就近放 10 μF + 0.1 μF，且要靠近芯片引脚 |

**几个必须理解的细节**：

- **nSLEEP 与 TB6612 的 STBY 功能等价、名字不同**。本板丝印写的是 `STBY1/STBY2`（沿用 TB6612 的叫法），实际芯片是 DRV8833，对应脚是 nSLEEP。功能上都是「拉高工作、拉低待机」，所以软件 `PB0/PB1 拉高` 是成立的；但**看丝印对引脚时必须知道这是两个器件的叫法差异**，否则会怀疑接错。
- **「符号-幅值」控制只用了半个真值表**：一路输入给 PWM、另一路保持低，就得到「单方向、可调速」；两路都低是滑行（高阻），两路都高是刹车（短接绕组）。刹车会让电机电流急剧反向，机械冲击大，所以本板不用刹车模式。
- **H 桥开关会产生电流尖峰**，去耦电容不是「滤波」，而是给这些尖峰提供**就近的电流源**。电容放远了，尖峰只能从电池组经长走线取电，走线电感会产生电压尖峰，可能超过 VM 绝对最大值。
- **热**：连续 1.5 A 时芯片会明显发热。带 PowerPAD 的封装必须**把散热焊盘焊到地铜上，并用过孔阵列把热导到内层/底层**；焊盘虚焊时表现是「空载正常、带载一会儿就保护」。

### 没吃透的地方

- 过流保护与 PWM 频率的关系（手册给了上限，但实际自热与保护动作点没有实测）；
- 是否需要电流采样电阻做闭环 —— 这直接关系到后续能否在没有编码器的情况下实现电流环。
