## 阶段一~三：参数化建模的基本功

| 阶段 | 关键做法 |
| --- | --- |
| 一 | 先定参数再画图（板厚、立柱间距、轮距写进参数表）；会成为零件的建为组件；保持时间轴干净；以地面、车体前端面、左右对称面为三个全局基准 |
| 二 | 草图自查闭环、完全约束、单位一致；先位置（水平/垂直/对称）再形状（相切/等长）最后细节尺寸；退出前拖动顶点自检：能动 = 欠约束，报红 = 过约束 |
| 三 | 直件对称拉伸保持中立面；立柱拉伸到对象，高度由参数驱动；叉齿用扫掠 + 相切圆弧过渡；开槽用拉伸减料；齿条单齿拉伸后矩形阵列 |

**遗留**：相切 + 等长 + 对称共存时求解器会选到非预期解，只能调添加顺序回避；重复齿形用草图阵列还是特征阵列尚无统一规范；扫掠路径曲率过大时自交，目前拆两段规避，无复用判据。

## 阶段四：叉车机构与齿条传动

把「方块携带」需要的升降动作做出来：叉车式门架 + 货叉 + 齿条驱动升降。

> ⚠️ 本阶段是**设计选型与三维建模**，尚未生成实物；「方块携带（单一 / 多项）」仍为未实现项。

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| **齿条 + 小齿轮** | 结构简单、行程不受长度限制、可与齿轮箱同轴 | 有回差、精度不如丝杆、需导向约束 | ✅ 采用 |
| 丝杆 | 精度高、可自锁 | 速度慢、行程受限、占空间 | ✗ |
| 同步带 | 快、轻 | 需张紧，直线导向仍要另做 | ✗ |

选齿条的理由是任务只要「举起来/放下去」，不要求毫米级定位，而它最省件、最易与现有底盘共用一个动力布置。

**设计基准**：齿距 $p=\pi m$、齿轮每转位移 $\pi m z$、齿条节线到齿轮中心 $mz/2$、全齿高约 $2.25m$（推导见《[机械学习记录](./机械学习记录.md)》）。由行程与驱动转速反推模数与齿数，再定齿条长度。

**建模要点**：

- 齿条节线、导轨中心、齿轮轴线用同一基准面与同一组参数驱动，几何上绑死——这是防止装上去啮合变楔紧的唯一可靠办法；
- 升降副在装配中只留**一个移动自由度**，其余配合锁死，否则模型能装、实物会晃；
- 货叉根部相切圆弧过渡，不留尖角；
- 参数表按依赖顺序写：行程 → 齿条长度 → 门架高度。

> ⚠️ **跨专业阻塞（同待确认项 X5）**：TIM1 四通道已用于四轮 PWM，方向脚占 PB12~PB15，使能占 PB0/PB1，TIM2/TIM3 已停用，**升降电机驱动通道尚未分配**。机械侧若确定用独立电机升降，需电控提前规划通道并同步文档 [01](./01-整体方案与硬件设计.md) 的引脚表。

其他遗留：齿条为简化齿廓，未做啮合运动仿真，卡齿风险未验证；接触强度未计算，厚度靠经验；回差未量化。

## 阶段五：整机装配与干涉检查

| 项目 | 做法 |
| --- | --- |
| 装配基准 | 地面 / 车体前端面 / 左右对称面，三个全局基准 |
| 层级 | 底盘组 / 电控硬件组 / 叉车机构组 / 电源组，分组装配 |
| 干涉检查 | 货叉最低位、最高位各查一次（最易与电池仓、车体打架） |
| 重心检视 | 直接读模型重心，判断前伸载荷是否让投影落在支撑多边形内 |
| 尺寸核对 | 长宽高从模型直读，与手册尺寸规范对照 |

**遗留**：干涉检查只覆盖最高/最低两个位置，中间行程与满载倾斜未查；180 mm 自由落体**未做**，实物测试是唯一判据；尺寸规范未实测；部分部件仍是视觉对齐，未用配合约束显式定义。

## 问题记录

| 问题 | 现象 | 原因 | 处理 |
| --- | --- | --- | --- |
| 草图改一处全乱 | 改完尺寸轮廓跑飞 | 靠鼠标拖出尺寸，无几何约束 | 改为约束优先、尺寸驱动 |
| 拉伸失败 | 提示轮廓无效 | 草图未闭环或多段线重叠 | 退出草图前自查闭环 |
| 扫掠失败 | 无法生成 | 路径与轮廓平面不相交 | 调整路径起点或换基准面 |
| 扫掠自交 | 弯钩处实体无效 | 路径曲率大于截面允许值 | 放大弯曲半径或拆两段扫掠 |
| 装配后改不动 | 改车体宽度要逐个挪部件 | 部件用绝对坐标定位 | 改为相对三个全局基准定位 |
| 升降副能装但会晃 | 模型可装配，自由度多于一个 | 配合约束未锁死多余自由度 | 显式定义单移动自由度 |
| 齿条啮合偏紧 | 理论位置装上后越走越沉 | 齿条与导轨平行度未绑同一基准 | 用同一参数驱动节线、导轨中心、齿轮轴线 |
