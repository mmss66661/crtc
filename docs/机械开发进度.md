## 总览

### 阶段主线

机械部分的推进是**从「画得出」到「装得上」再到「动得对」**：

1. **表达层**：能把一个想法用草图 + 几何约束 + 拉伸说清楚，模型完全约束、改参数不乱；
2. **成形层**：能处理非直棱柱结构（扫掠），把叉车式的悬臂与导向做出来；
3. **系统层**：能整机三维建模、分层装配，把叉车货叉 + 齿条升降在车体上装到位，且不与其他部件干涉。

## 阶段一（Fusion 360 与参数化建模）

### 阶段目标

建立「模型由参数驱动」的习惯，避免画出一堆改不动的图。

### 关键做法

| 做法 | 说明 |
| --- | --- |
| 先定参数再画图 | 把关键尺寸写进参数表（板厚、立柱间距、轮距），草图只引用参数 |
| 会成为零件的建成组件 | 组件带独立坐标系，后面才能单独出图、单独装配 |
| 保持时间轴干净 | 特征命名、及时重排，避免中间插入一步导致后序特征大面积报错 |
| 三个全局基准 | 地面、车体前端面、左右对称面，所有部件相对它们定位 |

## 阶段二（草图与几何约束）

### 阶段目标

让每张草图**完全约束**，形状关系由约束守住，而不是靠眼睛对齐。

### 关键做法

- 自查三件事：闭环、完全约束、单位一致；
- 尺寸定大小、几何约束定关系，两者分开加：先位置（水平/垂直/对称），再形状（相切/等长），最后细节尺寸；
- 退出草图前拖动顶点自检：能动 = 欠约束，报红 = 过约束。

### 遗留问题

- 相切 + 等长 + 对称共存时，求解器会选到不合预期的那个解，只能靠调整添加顺序回避；
- 齿条这类重复几何是「草图阵列」还是「特征阵列」，尚未形成统一规范。

---

## 阶段三（拉伸与扫掠成形）

### 阶段目标

能把结构件完整做出来：直件用拉伸，弯件用扫掠。

### 关键做法

| 结构 | 建模方法 | 理由 |
| --- | --- | --- |
| 底板、连接板 | 草图 → 对称拉伸 | 对称拉伸保持中立面，装配时不用算偏移 |
| 立柱、门架型材 | 草图 → 拉伸（到对象/贯穿） | 高度由参数驱动，改门架高不动草图 |
| 叉齿主体 | 轮廓 → 扫掠（沿弯钩路径） | 弯折过渡用相切圆弧，避免根部尖角应力集中 |
| 开槽、让位 | 拉伸减料（Cut），不用重建体 | 布尔减料比后组合更稳，不破坏历史 |
| 齿条单齿 | 单齿廓 → 拉伸 → 矩形阵列 | 参数化最干净，改齿数只改阵列数量 |

### 遗留问题

- 扫掠路径曲率过大时会自交失败，目前靠拆成两段扫掠规避，还没有可复用的判断规则；
- 变截面叉齿（如果后续需要减重）普通扫掠做不到，需要换更复杂的输入方式。

## 阶段四（叉车机构与齿条传动）

### 阶段目标

把「方块携带」需要的升降动作做出来：叉车式门架 + 货叉 + 齿条驱动升降。

> ⚠️ **状态说明**：本阶段是**设计选型与三维建模**，尚未生成实物。README 中「方块携带（单一 / 多项）」仍为未实现项，本文档不改变该结论。

### 机构选型

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| **齿条 + 小齿轮** | 结构简单、直线行程不受长度限制、可与齿轮箱同轴直连 | 有回差、精度不如丝杆、需导向约束 | ✅ 采用 |
| 丝杆 | 精度高、可自锁 | 速度慢、行程受限、同轴布置更占空间 | ✗ |
| 同步带 | 快、轻 | 需要张紧、直线导向仍要另做 | ✗ |

选齿条的理由是**任务只要「举起来/放下去」，不要求毫米级定位**，而齿条在结构上最省件、最容易和现有四轮底盘共用一个动力布置。

### 齿条-齿轮几何关系（设计基准）

| 量 | 关系 | 用途 |
| --- | --- | --- |
| 齿距 | $p = \pi m$ | 由模数决定齿距 |
| 齿轮每转位移 | $\pi m z$ | 由行程与电机转速反推齿数/模数 |
| 齿条节线到齿轮中心 | $m z / 2$ | 决定齿轮轴与齿条安装面的距离 |
| 全齿高 | $\approx 2.25 m$ | 决定门架让位空间 |

### 建模要点

- **齿条节线、导轨中心、齿轮轴线用同一个基准面与同一组参数驱动**，让三者在几何上就绑死 —— 这是防止「装上去啮合变成楔紧」的唯一可靠办法；
- 升降副在装配里只保留**一个移动自由度**，其余全部用配合约束锁死，否则模型能装、实物会晃；
- 货叉根部用相切圆弧过渡，不用尖角；
- 升降行程决定齿条长度，齿条长度又反过来影响门架高度，参数表里要按依赖顺序写。

### 遗留问题

> ⚠️ **跨专业阻塞（需要与电控确认）**：STM32 的 TIM1 四个通道已全部用于四轮 PWM（PA8~PA11），方向脚占 PB12~PB15，使能占 PB0/PB1；CubeMX 里的 TIM2/TIM3 已被停用以避免占用 PS2 与 STBY 引脚。**升降电机的驱动通道目前没有分配**。机械侧若确定采用独立电机驱动升降，需要在电控侧提前规划通道（并同步更新文档 [01](./01-整体方案与硬件设计.md) 的引脚表），否则机械做完装不上电。

其他遗留：

- 齿条用简化齿廓，只保证「能装上」，未做啮合运动仿真，卡齿风险未验证；
- 齿条与齿轮的接触强度未计算，厚度靠经验；
- 回差没有量化，若后续要求定位精度需加锁止或补偿。

## 阶段五（整机装配与干涉检查）

### 阶段目标

整机三维建模成型，各部件装得上、动得开、不互相打架。

### 关键做法

| 项目 | 做法 |
| --- | --- |
| 装配基准 | 地面 / 车体前端面 / 左右对称面，三个全局基准 |
| 层级 | 底盘组 / 电控硬件组 / 叉车机构组 / 电源组，分组装配 |
| 干涉检查 | 货叉最低位、最高位各查一次（这两个位置最容易与电池仓、车体打架） |
| 重心检视 | 直接用模型读重心位置，判断前伸载荷是否让重心出支撑多边形 |
| 尺寸核对 | 整机长宽高从模型直接读，与手册尺寸规范对照 |

### 遗留问题

- 干涉检查只覆盖最高/最低两个位置，中间行程与满载倾斜工况未查；
- 结构稳定性（手册要求的 180 mm 自由落体）**未做**，模型阶段只能看薄弱件，实物测试是唯一判据；
- 尺寸规范尚未用实测数据核对，模型尺寸与实物存在装配误差；
- 部分部件仍是视觉对齐，没有用配合约束显式定义。

## 问题记录

| 问题 | 现象 | 原因 | 处理 |
| --- | --- | --- | --- |
| 草图改一处全乱 | 改完尺寸后轮廓跑飞 | 靠鼠标拖出的尺寸，没有几何约束 | 改为约束优先、尺寸驱动 |
| 拉伸失败 | 提示轮廓无效 | 草图未闭环或多段线重叠 | 退出草图前自查闭环 |
| 扫掠失败 | 无法生成 | 路径与轮廓平面不相交 | 调整路径起点或换基准面 |
| 扫掠自交 | 弯钩处生成无效实体 | 路径曲率大于截面允许值 | 放大弯曲半径或拆两段扫掠 |
| 装配后改不动 | 改车体宽度要逐个挪部件 | 部件相对位置是绝对坐标 | 改为相对三个全局基准定位 |
| 升降副能装但会晃 | 模型能装配，自由度多于一个 | 配合约束没锁死多余自由度 | 显式定义单移动自由度 |
| 齿条啮合偏紧 | 理论位置装上后越走越沉 | 齿条与导轨平行度未绑定同一基准 | 用同一参数驱动节线、导轨中心、齿轮轴线 |
