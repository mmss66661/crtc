## 第一阶段（9.25–10.1）STM32 与 HAL 库入门

打通**编译 → 烧录 → 运行**的最小闭环。

| 知识点 | 掌握程度（自评） |
| --- | --- |
| 工程构建：CubeMX + CMake/Ninja + `arm-none-eabi-gcc` | 已掌握 |
| 时钟树：HSE 8 MHz → PLL×9 → 72 MHz，AHB/APB1/APB2 分频 | 已掌握 |
| GPIO：推挽/开漏、复用（AF_PP）、上下拉、软件模拟时序 | 已掌握 |
| PWM：计数模式、PSC/ARR、CCR 调占空比、高级定时器 MOE | 已掌握 |
| SPI：全双工四线、CPOL/CPHA、片选 | 理解原理，未独立实现 |
| 调试：SWD 四线、ST-LINK 烧录与在线读寄存器 | 已掌握 |

**关键理解**：SPI 是带时序的全双工通信，适合遥控这类周期短帧低延迟链路；PWM 的本质是脉冲方波，占空比经 H 桥被电机「积分」成平均电压；GPIO 的价值在通用性，既是方向脚，也是硬件资源不够时模拟时序的兜底。

**验证**：CMake + Ninja 命令行无警告编译、ST-LINK 反复烧录且读回一致、LED 按预期闪烁。

**遗留**：SPI 只停在原理层，直到第三阶段接 PS2 才补上手写时序；未接触中断与 DMA，逻辑全为轮询。

## 第二阶段（10.1–10.5）经典控制理论（PID）

把「给固定占空比」升级为「给目标转速」，建立误差—反馈的闭环思维。

| 知识点 | 掌握程度（自评） |
| --- | --- |
| P 控制：误差 × 比例系数，即时主控制量，本身带惯性 | 已掌握 |
| I 控制：累积误差消静差；大阶跃易超调，需限幅 + 积分分离 | 已掌握 |
| D 控制：对误差变化率响应，起阻尼作用 | 部分理解（高频振荡机理未吃透） |
| 位置式 / 增量式、采样周期对参数的影响 | 已掌握 |

**关键理解**：P 是主力、I 补静差、D 加阻尼；积分必须设上限，否则阶跃饱和后退不下来；PD 常用于位置控制，落点稳不来回振荡。尚未吃透的是 D 项为何在时域引起高频振荡——目前判断是差分放大采样噪声，还没有实验证实。

**验证**（台架，TT 马达 ×1）：先 P 后 I 再 D，逐项加、单项观测；纯 P 有稳态误差，加 I 后静差收敛，加大 I 出现超调，与理论一致。

> ⚠️ **口径（同待确认项 X1）**：本阶段为**台架验证**，整车 `Chassis/` 仍是开环 PWM + ±28 死区，没有编码器反馈，不可表述为「整车 PID 闭环」。另需补写闭环反馈量是编码器、霍尔还是反电动势估算。

## 第三阶段（10.6–10.13）底盘运动学（麦轮解算）

解决「车体速度」如何分配到「四个轮子转速」，即平面运动的逆运动学。

| 知识点 | 掌握程度（自评） |
| --- | --- |
| 线量/角量：线位移、线速度、线加速度与角量三者 | 已掌握 |
| 合成与分解：刚体平面运动 = 平动 + 转动 | 已掌握 |
| 正解 / 逆解：由轮速求车体速度，或反向 | 已掌握 |
| 麦轮特性：辊子 45° 布置，四轮组合实现全向移动 | 已掌握 |

**关键理解**：线量与角量既可合成也可分解，正逆解是同一组关系的两个方向；车体速度分为 $V_x$、$V_y$、$\omega$，各轮按辊子方向分解后线性组合即可还原车体速度。设计上把运动学集中在 `ChassisCtrl::update(v, turn)`，底层 `Motor::set_speed()` 不动，**换底盘构型只替换这一个函数**。

**验证**：由辊子方向建立四轮速度与 $(V_x, V_y, \omega)$ 的线性方程组，推导完成并落到代码；实车未落地。

> ⚠️ **口径（同待确认项 X2）**：本阶段完成的是**理论推导**，实车为 TT 马达差速（`left = v - turn/2`，`right = v + turn/2`），文档 [01](./01-整体方案与硬件设计.md) 也说明了「先差速、后麦轮」的选型理由。麦轮全向移动的前提是四轮转速精确标定，而当前没有编码器，这一前提尚不成立。

## 第四阶段（10.13–10.18）现代控制理论（六轴机械臂逆解）

从平面 3 自由度扩展到空间 6 自由度，平台为 **ROS2 + MoveIt**。DH 参数、连杆变换矩阵与雅可比推导过程见《[电控学习记录](./电控学习记录.md)》。

| 知识点 | 掌握程度（自评） |
| --- | --- |
| DH 参数（$\theta_i$、$d_i$、$a_i$、$\alpha_i$） | 已掌握 |
| 相邻连杆变换与正解 $^0T_n = \prod {}^{i-1}T_i$ | 已掌握 |
| 雅可比与逆解 $\partial x = J(q)\,\partial q$ | 部分理解 |
| ROS2 节点组织、MoveIt 规划与 IK 求解器 | 会用，原理待深入 |

**关键理解**：雅可比矩阵把关节空间微变量映射到任务空间微变量，逆解即沿此关系迭代逼近目标位姿。

**验证**：按六轴结构填写 DH 表并核对正解末端位姿；MoveIt 给定目标位姿可求解关节角，但奇异位形与多解选择未系统梳理。

**遗留**：逆解多解（肘上/肘下、腕翻转）与奇异位形未验证；仍依赖数值迭代，未推导本构型解析解；底盘 3 自由度与臂 6 自由度尚未合成移动操作模型。
