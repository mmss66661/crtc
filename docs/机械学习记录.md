工具只用 **Autodesk Fusion 360**，因为它把草图、约束、拉伸、扫掠、装配放在同一条**参数化时间轴**上，改一个参数整条链自动重算，适合还在反复改结构的阶段。

---

## 1. 建模是一条可以回退的时间轴

- **模型不是「一堆面」，而是一串特征的历史**：双击任意一步即可改参数，后续特征自动重算。所以建模顺序本身就是设计决策——顺序错了，改起来比重新画还慢。
- **参数表是核心价值**：把关键尺寸（叉齿长、门架高、齿条模数）写成用户参数，所有草图与特征引用参数，改一个数整机联动。这是「三维建模」与「画个图看看」的分界。
- **实体（Body）与组件（Component）要分清**：实体只是几何体，组件带独立坐标系、可单独出图、可参与装配。规则一句话：**会成为独立零件的，建成组件**——一开始全建在一个实体里，后面做装配只能痛苦拆分。
- **首件自顶向下、细节自底向上**：总体尺寸在装配层用参考几何定下，单个零件再在组件内细化。

常见坑：鼠标拖出的尺寸「看着对」但没参数驱动；时间轴中间插一步改倒角，后面依赖该面的特征全部报错。

---

## 2. 草图：所有实体的来源

- **草图是特征的输入**，拉伸、扫掠、旋转都只能吃二维轮廓；轮廓不封闭、有多余交点、线段重叠，特征必然失败。
- **草图平面决定零件主方向**：在哪张基准面上画，就决定了零件「哪一面是正面」。选错不报错，但后续所有参考方向都别扭。
- **构造线**用来建参考中心、对称轴、节圆；轮廓只保留真正要成形的部分。
- **投影已有几何（Project）**把孔位、边界引进草图，上游尺寸一改，投影跟着变。
- **退出前拖一下顶点**：能动 = 约束不足；纹丝不动且线条全黑 = 完全约束。

> 自查三件事：是否闭环、是否完全约束、单位是否一致。草图阶段处理只要一分钟，到特征阶段要一小时。

---

## 3. 几何约束：让形状自己守住关系

**尺寸定「多大」，几何约束定「什么关系」**，两者配合才能完全约束。只标尺寸不做约束，草图会用一堆奇怪的自动关系把形状锁死在你没想到的地方。

| 约束 | 用途举例 |
| --- | --- |
| 重合 | 轮廓首尾相接，保证闭环 |
| 水平 / 垂直 | 门架立柱、地面基准 |
| 平行 / 垂直 | 齿条与导轨的相对位置 |
| 相切 | 货叉弯钩处的圆弧过渡，避免应力集中 |
| 等长 | 四根立柱、成对叉齿长度一致 |
| 对称 | 货叉左右对称布置 |
| 中点 | 齿条中段与齿轮啮合位置居中 |
| 固定 | 零件相对原点的定位锚点 |

- **欠约束是不稳定，过约束是矛盾**：欠约束几何可自由滑动，尺寸链会「漂」；过约束求解器直接报错。
- **约束优先级高于尺寸**：加了「水平」再标斜向尺寸就是冲突，先想清楚要哪种关系再加约束。
- **约束顺序影响求解结果**：同样的约束与尺寸，加的顺序不同可能给出不同的解（尤其对称与相切共存时），所以按「先位置、后形状、再细节」加。

**没吃透**：相切 + 等长 + 对称共存时，为何有时存在两个合理解而 Fusion 选了不想要的那个，目前只能调顺序绕过去；齿条这类重复几何，草图阵列与特征阵列对完全约束的影响还没系统对比。

## 4. 拉伸：从二维到 3D 的第一步

绝大多数结构件（底板、立柱、连接板、叉齿主体）都由拉伸得到。

| 选项 | 作用 | 常见用途 |
| --- | --- | --- |
| 方向 / 距离 | 单向、对称、两侧 | 对称件用「对称」保证基准面居中 |
| 到对象 / 贯穿 | 拉伸到指定面或穿透所有 | 打孔、开槽不用手算深度 |
| 布尔（加/减/交） | 新建、合并、切除、求交 | 减料做槽与孔 |
| 拔模（Taper） | 侧壁带斜度 | 需脱模或减小摩擦的导向面 |

**对称拉伸保持中立面**：以零件中心面为草图平面、向两侧对称拉伸，后续特征都能以原点对称，装配时不用反复算偏移。**减料（Cut）比新建再组合更稳**，直接在一次拉伸里做减料，不容易破坏已有特征历史。轮廓需要沿曲线走时（弯钩、弧线过渡）就必须换扫掠。

---

## 5. 扫掠：让截面沿路径走

**扫掠 = 轮廓沿路径运动成体**，是拉伸的推广：拉伸的路径是直线，扫掠的路径可以是任意曲线。典型用法是恒截面弯管/弯钩（货叉弯折过渡、导向槽）与沿导轨的异型材。

- **路径必须与轮廓平面相交**，否则直接失败——这是最常见的报错原因，不是软件坏了。
- **曲率过大会自交**：截面在急弯处自己穿过自己，生成无效实体。放大弯曲半径、缩小截面，或把一段弯拆成两段扫掠再拼。
- **扭转（Twist）非必要不开**：一加扭转，截面在路径上的姿态就由软件插值决定，可预测性变差。

| 想要的形状 | 选哪个 | 原因 |
| --- | --- | --- |
| 直棱柱、板、柱 | 拉伸 | 约束少、时间轴短、改尺寸最方便 |
| 沿曲线走、截面不变的杆件 | 扫掠 | 拉伸做不到沿曲线 |
| 变截面（如锥形叉齿） | 扫掠 / 放样 | 输入更复杂，只在必要时用 |
| 大量重复齿形 | 拉伸单齿 + 阵列 | 比扫掠可控，参数化更好维护 |

## 6. 齿条：把旋转变成直线

**齿条本质上是「半径无穷大的齿轮」**，与齿轮啮合把旋转变成直线。相对丝杆与同步带，优势是结构简单、行程不受限制、可与齿轮同轴；代价是有回差、精度不如丝杆、需要导向。

| 量 | 关系 | 说明 |
| --- | --- | --- |
| 齿距 $p$ | $p = \pi m$ | 相邻同侧齿廓的直线距离 |
| 齿条每齿位移 | $\pi m$ | 齿轮转一个齿，齿条走一个齿距 |
| 齿轮每转位移 | $\pi m z$ | 小齿轮转一圈，齿条前进的距离 |
| 中心距（齿条） | $m z / 2$ | 齿条节线到齿轮中心的距离 |
| 齿高 | $\approx 2.25 m$ | 全齿高（含顶隙） |

**「每转位移 = π m z」是设计升降行程的起点**：给定行程与驱动方式，反推小齿轮齿数与模数，再定齿条长度。

**两条建模路线**：拉伸单齿 + 矩形阵列（参数化最干净，改齿数只改阵列数量，推荐）；齿廓沿齿条长度扫掠（路径是直线时结果等价于拉伸，反而多一层依赖）。

**关键不是齿形，而是齿条与导轨的平行度**：齿条歪一点，啮合就变楔紧，表现为「越走越沉、最后卡死」。所以**齿条节线、导轨中心、齿轮轴线**应当用同一基准面与同一组参数驱动。回差也要预留——要求定位精度时需额外锁止或补偿，不能指望齿条自己消隙。

**没吃透**：渐开线与简化圆弧齿廓对啮合平顺度的影响（现用简化齿廓，只保证「看起来合理、能装上」，未做运动仿真）；齿条与齿轮的接触强度没算过，载荷全靠经验留厚度。

## 7. 叉车：悬臂结构 + 直线副

- **三个组成部分**：门架（导向与承力）、货叉（承载）、升降副（齿条传动或滑轨导向）。按这三部分分层建组件，装配关系才清晰。
- **货叉是典型悬臂梁**：载荷压在前伸段，根部弯矩最大，所以根部过渡不能是尖角——尖角既要承受最大弯矩又产生应力集中，造型上用相切圆弧过渡。
- **倾覆比强度更容易先发生**：载荷 × 前伸距离 与 车体自重 × 轮距 之间必须留够余量，否则电机转得动、车却翻了。三维建模里可直接读**重心位置**检视，不必等实物。
- **自由度要用装配约束显式定义**：升降副只允许一个移动自由度，多给一个，模型能装、实物就晃。
- **导向长度决定卡滞风险**：滑动配合导向面太短会「翘头」，不够时不是加厚，而是加长导向段。

建模层面：以地面、车体前端面、左右对称面三个基准定位所有部件；用参数表驱动门架高度、叉齿长度、齿条行程、啮合中心距；定期在货叉最低位与最高位跑干涉检查。

**没吃透**：倾覆余量的定量判据（投影落在支撑多边形内、留多少算安全）只做定性判断；升降速度与齿条强度的取舍没验证，模数靠经验选。

---

## 8. 待补的功课

齿条齿廓需做一次啮合仿真；干涉检查要加中间位置与满载倾斜工况；重心与倾覆要算出具体余量；齿条、导轨、齿轮的中心距应统一到一个参数；装配自由度需逐个用配合约束显式定义。进度与风险跟踪见《[机械开发进度](./机械开发进度.md)》。
