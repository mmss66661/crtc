## 1. Fusion 360：建模是一条可以回退的时间轴

### 理解

- **Fusion 360 的模型不是「一堆面」，而是一串特征的历史**。时间轴上的每个特征都是对前一步结果的一次操作，双击任意一步就能改它的参数，后面的特征自动重算。所以建模顺序本身就是设计决策 —— 顺序错了，改起来比重新画还慢。
- **参数化（参数表）是它的核心价值**：把关键尺寸写成用户参数（如 `叉齿长`、`门架高`、`齿条模数`），所有草图与特征引用参数。改一个数，整机联动。这是「三维建模」和「画个图看看」的分界。
- **实体（Body）与组件（Component）要分清**：实体只是几何体，组件带独立的坐标系、可以单独出图、可以参与装配。一句话规则：**会成为独立零件的，建成组件**。一开始偷懒全建在一个实体里，后面要做装配时只能痛苦拆分。
- **首件自顶向下、细节自底向上**：总体尺寸（占地、高度、接口位置）先在装配层用参考几何定下来，单个零件再在组件内部细化。反过来的话，每个零件都画得很漂亮，装到一起装不上。

### 容易踩的点

- 用鼠标直接拖出来的尺寸「看着对」但没有参数驱动，改一个地方全乱；
- 时间轴中间插了一步「改倒角」，后面所有依赖该面的特征全部报错 —— 这类依赖断裂是参数化建模最常见的维护成本。

## 2. 草图：所有实体的来源

### 理解

- **草图是特征的输入，不是独立的图形**。拉伸、扫掠、旋转都只能吃二维轮廓，所以草图质量直接决定特征能不能生成。轮廓不封闭、有多余交点、线段重叠 —— 特征是必然失败的。
- **草图平面的选择等价于决定零件的主方向**：在哪个基准面上画图，就决定了这个零件「哪一面是正面」。选错平面不会报错，但后续所有特征的参考方向都别扭。
- **构造线（Construction）和不参与轮廓的辅助线**是好工具：用构造线建参考中心、对称轴、节圆，轮廓只保留真正要成形的部分。
- **投影已有几何（Project）能让草图与上游对齐**：把孔位、边界投影进来，后续改了上游尺寸，投影跟着变。
- **草图一定要拖一下检验**：退出草图前拖动轮廓顶点，如果它能动，说明约束不足；如果它纹丝不动且全部线条变黑，说明完全约束。

### 记住的一条

> 草图画完先自查三件事：是否闭环、是否完全约束、单位是否一致。这三件在草图阶段处理只要一分钟，到特征阶段处理要一小时。

## 3. 几何约束：让形状自己守住关系

### 理解

- **尺寸定「多大」，几何约束定「什么关系」**。两者配合才能完全约束。只标尺寸不做约束，草图会用一堆奇怪的自动关系把形状锁死在你没想到的地方。
- **常用几何约束及其用途**：

| 约束 | 用途举例 |
| --- | --- |
| 重合 | 轮廓首尾相接，保证闭环 |
| 水平 / 垂直 | 门架立柱、地面基准 |
| 平行 / 垂直 | 齿条与导轨的相对位置 |
| 相切 | 货叉弯钩处的圆弧过渡，避免应力集中 |
| 等长 | 四根立柱、成对叉齿长度一致 |
| 对称 | 叉车货叉左右对称布置 |
| 中点 | 齿条中段与齿轮啮合位置居中 |
| 固定 | 整个零件相对原点的定位锚点 |

- **欠约束是不稳定，过约束是矛盾**：欠约束时几何可以自由滑动，尺寸链会「漂」；过约束时求解器直接报错，因为它无法同时满足互相矛盾的约束。判断方法简单：拖动能动的就是欠约束，报红的就是过约束。
- **约束的优先级高于尺寸**：加了「水平」约束，再标一个斜向尺寸就是过约束冲突。先想清楚要哪种关系，再加对应约束，不要先标一堆尺寸再硬凑。
- **约束顺序影响求解结果**：同样的尺寸与约束，加的顺序不同，求解器可能给出不同的解（尤其在对称与相切共存时）。所以建模时按「先位置、后形状、再细节」的顺序加。

### 没吃透的地方

- 相切 + 等长 + 对称同时存在时，为什么有时会出现「有两个合理解、Fusion 选了我不想要的那个」，目前只能靠调整添加顺序绕过去，没搞清求解器的选择规则；
- 齿条齿廓这类**大量重复几何**，是在草图里阵列还是画一个齿再阵列特征，两者对完全约束的影响还没有系统对比过。

## 4. 拉伸：从二维到 3D 的第一步

### 理解

- **拉伸把闭合草图沿法向挤出成实体**，是最主要、最可靠的成形手段。绝大多数结构件（底板、立柱、连接板、叉齿主体）都是拉伸出来的。
- **四个关键选项**：

| 选项 | 作用 | 常见用途 |
| --- | --- | --- |
| 方向 / 距离 | 单向、对称、两侧 | 对称件用「对称」可以保证基准面居中 |
| 到对象 / 贯穿 | 拉伸到指定面或穿透所有 | 打孔、开槽时不用手算深度 |
| 布尔（加/减/交） | 新建、合并、切除、求交 | 减料做槽与孔，求交做配合面 |
| 拔模（Taper） | 侧壁带斜度 | 需要脱模或减小摩擦的导向面 |

- **「对称拉伸」是保持中立面的关键**：以零件中心面为草图平面、向两侧对称拉伸，后续所有特征都能以原点对称，装配时不用反复算偏移。
- **减料（Cut）比新建再组合更稳**：开孔直接在一次拉伸里做减料，比重建实体再做布尔运算更不容易破坏已有特征的历史。
- **拉伸不擅长弯曲结构**：一旦轮廓需要沿曲线走（弯钩、导轨、沿弧线的叉齿过渡），就必须换扫掠。

## 5. 扫掠：让截面沿路径走

### 理解

- **扫掠 = 轮廓（Profile）沿路径（Path）运动成体**。它是拉伸的推广：拉伸的路径是一条直线，扫掠的路径可以是任意二维/三维曲线。
- **路径必须与轮廓平面相交**，否则扫掠直接失败。这是最常见的报错原因，不是软件坏了。
- **路径曲率过大会导致自交**：截面在急弯处会「自己穿过自己」，生成无效实体。要么放大弯曲半径，要么缩小截面，要么把一段弯拆成两段扫掠再拼。
- **扫掠的三种典型用法**：
  1. **恒截面弯管/弯钩**：货叉的弯折过渡段、导向槽；
  2. **沿导轨的异型材**：门架导轨的截面沿直路径扫掠，等价于拉伸但截面朝向更好控；
  3. **沿螺旋/曲线的传动件**：本机不涉及，但同一条思路可以处理螺旋线。
- **扭转（Twist）选项很少用是对的**：一旦加扭转，截面在路径上的姿态就由软件插值决定，可预测性变差，非必要不开。

### 与拉伸怎么选

| 想要的形状 | 选哪个 | 原因 |
| --- | --- | --- |
| 直棱柱、板、柱 | 拉伸 | 约束少、时间轴短、改尺寸最方便 |
| 沿曲线走、截面不变的杆件 | 扫掠 | 拉伸做不到沿曲线 |
| 变截面（如锥形叉齿） | 扫掠 / 放样，视路径而定 | 需要更复杂的输入，只在必要时用 |
| 大量重复齿形 | 拉伸单齿 + 阵列 | 比扫掠可控，参数化更好维护 |

## 6. 齿条：把旋转变成直线

### 理解

- **齿条本质上就是「半径无穷大的齿轮」**，与齿轮啮合时把旋转运动变成直线运动。相对于丝杆、同步带，它的优势是**结构简单、直线行程不受长度限制、可以直接与齿轮同轴**；代价是**有回差、精度不如丝杆、需要导向约束**。
- **基本几何关系**（模数 $m$、齿数 $z$）：

| 量 | 关系 | 说明 |
| --- | --- | --- |
| 齿距 $p$ | $p = \pi m$ | 相邻同侧齿廓的直线距离 |
| 齿条每齿位移 | $\pi m$ | 齿轮转一个齿，齿条走一个齿距 |
| 齿轮每转位移 | $\pi m z$ | 小齿轮转一圈，齿条前进的距离 |
| 中心距（齿条） | $m z / 2$ | 齿条节线到齿轮中心的距离 |
| 齿高 | $\approx 2.25 m$ | 全齿高（含顶隙） |

- **「每转位移 = π m z」这条公式是设计叉车升降行程的起点**：给定行程与驱动方式，反推出小齿轮齿数与模数，再决定齿条长度。
- **齿条建模的两条路线**：

| 路线 | 做法 | 优缺点 |
| --- | --- | --- |
| 拉伸 + 阵列 | 画一个齿的轮廓 → 拉伸到齿宽 → 矩形阵列覆盖长度 | 参数化最干净，改齿数只改阵列数量；推荐 |
| 扫掠 | 齿廓沿齿条长度方向扫掠 | 路径是直线时结果与拉伸等价，反而多一层依赖 |

- **齿条的关键不是齿形本身，而是齿条与导轨的平行度**：齿条歪一点，啮合就变成楔紧，表现为「越走越沉、最后卡死」。建模时应当把**齿条节线、导轨中心、齿轮轴线**用同一个基准面与同一组参数驱动，让三者几何上也绑在一起。
- **回差要预留**：齿条/齿轮啮合必然有间隙，紧急升降机构若对定位精度要求高，需要额外的锁止或补偿，不能指望齿条自己消隙。

### 没吃透的地方

- 齿条齿廓的精确画法（渐开线与简化圆弧齿廓）对实际啮合平顺度的影响，目前用的是简化齿廓，只能保证「看起来合理、能装上」，没有做运动仿真验证；
- 齿条与齿轮的**接触强度**没有算过，叉车载荷全靠经验留厚度。

## 7. 叉车：悬臂结构 + 直线副

### 理解

- **叉车机构的三个组成部分**：门架（导向与承力）、货叉（承载）、升降副（齿条传动或滑轨导向）。建模时按这三部分分层建组件，装配关系才清晰。
- **货叉是最典型的悬臂梁**：载荷全部压在前伸段，根部弯矩最大。所以建模时**根部的过渡不能做成尖角** —— 尖角既要承受最大弯矩又产生应力集中，是结构上最先出问题的地方。造型上用相切圆弧过渡，既是强度需要也是美观需要。
- **倾覆比强度更容易先发生**：叉车式机构把载荷送到车体轮廓之外，重心前移。载荷 × 前伸距离 与 车体自重 × 轮距 之间必须留够余量，否则电机转得动、车却翻了。这一点在三维建模里可以用**重心位置**直接检视，不必等实物。
- **自由度要用装配约束显式定义**：升降副只允许一个移动自由度。多给一个自由度，模型能装、实物就会晃。用**滑块类配合**约束方向，把其余五个自由度全部锁死。
- **导向长度决定卡滞风险**：升降的滑动配合，导向面太短会「翘头」。长度不够时不是加厚，而是加长导向段。

### 三维建模层面的做法

- 在装配里用参考几何定三个基准：**地面**、**车体前端面**、**左右对称面**。所有部件都相对这三个基准定位，后面改车体宽度时整机跟着变，不用一个个挪。
- 用**参数表**驱动关键尺寸：门架高度、叉齿长度、齿条行程、啮合中心距。改行程 → 齿条长度、门架高度、货叉位置自动更新。
- 定期跑**干涉检查**：叉齿降到最低位、升到最高位各检查一次，因为这两个位置最容易与车体/电池仓打架。

### 没吃透的地方

- 倾覆余量的定量判据（重心投影落在支撑多边形内、且留多少余量算安全）只做了定性判断，没有算过具体数值；
- 升降速度与齿条强度之间的取舍没有验证，靠经验选模数。
