## 分册概要

文档分两组：**01~04 按功能板块**写「做成了什么」，**05~10 按专业分册**写「怎么学会的、进行到哪一步」。每个专业分册都是「学习记录 + 进度记录」成对出现：学习记录写理解与未吃透的地方，进度记录写做法、验证与遗留问题。

| 专业 | 学习记录 | 进度记录 | 工具 / 关键词 | 当前阶段 |
| --- | --- | --- | --- | --- |
| 电控 | [05](./电控学习记录.md) | [06](./电控开发进度.md) | STM32 HAL、PID、运动学逆解、ROS2 + MoveIt | 四轮开环 PWM 已跑通；速度闭环在台架，PS2 未联调 |
| 硬件 | [07](./硬件学习记录.md) | [08](./硬件开发记录.md) | 嘉立创 EDA / 立创商城 / 嘉立创打样；引脚、VCC/GND、LDO、DCDC、DRV8833、走线 | 主控板已打样并跑通四轮驱动 |
| 机械 | [09](./机械学习记录.md) | [10](./机械开发进度.md) | Autodesk Fusion 360；草图、几何约束、拉伸、扫掠、齿条、叉车、三维建模 | 结构件完成；叉车升降机构建模中，未装车 |

### 各专业结论速览

- **电控**：器件层（GPIO / PWM / SPI、72 MHz 时钟树）→ 控制层（PID，仅台架验证）→ 运动学层（麦轮解算已推导、六轴臂逆解在 ROS2 + MoveIt 上验证）。解算层与驱动层已解耦，换底盘构型只需替换 `ChassisCtrl::update()`。
- **硬件**：主控、两颗 DRV8833、电源转换与接口合在一张 2 层板上，电源为「电池 → VM 直供驱动 / DCDC 5 V → LDO 3.3 V 主控」。核心教训是**引脚规划必须与软件预期逐项核对** —— 多数问题不是焊接，而是原理图阶段脚位与软件不一致。
- **机械**：Fusion 360 参数化链路（草图 → 几何约束 → 拉伸 → 扫掠）已成型；叉车式门架 + 货叉 + 齿条升降为「方块携带」的设计选型，齿条-齿轮几何关系（$p=\pi m$、每转位移 $\pi m z$、节线距 $mz/2$）已作为设计基准。

## 关于开源项目的说明

本项目**未使用任何第三方开源机器人项目或开源控制代码**。所用外部资源仅限：

| 名称 | 来源 | 协议 | 用途 |
| --- | --- | --- | --- |
| STM32Cube HAL 库（STM32F1xx HAL Driver） | STMicroelectronics 官方 | BSD-3-Clause（随 STM32Cube 发布） | MCU 外设初始化与驱动 |
| CMSIS Core / Device 头文件 | Arm / STMicroelectronics 官方 | Apache-2.0 / BSD-3-Clause | Cortex-M3 内核寄存器定义 |
| STM32CubeMX 生成的工程骨架 | STMicroelectronics 官方工具自动生成 | 同上 | 时钟、GPIO 初始化模板 |

底盘差速解算、电机控制类（`Chassis/`）、PS2 协议帧（`PS2/`）均为本队自行编写。
各开源组件的许可证原文随源码保留在 `Drivers/` 目录下（`LICENSE.txt`）。
