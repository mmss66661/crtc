## 跨分册待确认项

以下**分册之间**存在口径差异或依赖，提交前需统一：

| 编号 | 事项 | 相关分册 | 说明 |
| --- | --- | --- | --- |
| X1 | PID 闭环是台架还是整车 | 电控 05 / 02 | 整车 `Chassis/` 仍是开环 PWM + ±28 死区，应表述为「台架已验证、整车未集成」 |
| X2 | 麦轮解算是否已装车 | 电控 05 / 01、02 | 实车为 TT 马达差速，麦轮仅完成推导 |
| X3 | 板面 `+12V` 丝印与 2S 电池不匹配 | 硬件 08 / 01 | 实物电池组标称 12 V，而方案写 2 节 18650（7.4 V），需确认实际供电与升压环节 |
| X4 | 降压电路是板载还是外挂模块 | 硬件 08 / 01 | 已按 V1.0 原理图确认为**板载自绘两级降压**（LM2575S-5.0 → AMS1117-ADJ），01 需同步改写 |
| X5 | 升降电机驱动通道未分配 | 机械 10 / 电控、硬件 | TIM1 四通道已占满，机械做完会装不上电 |

## 关于开源项目的说明

本项目**未使用任何第三方开源机器人项目或开源控制代码**。外部资源仅限 STM32Cube HAL 库（BSD-3-Clause）、CMSIS Core/Device 头文件（Apache-2.0 / BSD-3-Clause）与 STM32CubeMX 生成的工程骨架，许可证原文随源码保留在 `Drivers/` 目录下（`LICENSE.txt`）。

底盘差速解算、电机控制类（`Chassis/`）、PS2 协议帧（`PS2/`）均为本队自行编写。
